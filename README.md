LearnKids Web

------ Descripción del proyecto: 
LearnKids Web es una aplicación web educativa desarrollada para gestionar recursos educativos dirigidos a niños. Permite registrar, consultar, visualizar, actualizar y eliminar recursos desde una interfaz web.

------- Objetivo
Implementar un sistema web que facilite la administración de recursos educativos mediante operaciones CRUD, utilizando Java, Servlets, JSP y conexión a una base de datos MySQL.

------- Tecnologías utilizadas
Java 25.
Java Servlets.
JSP (JavaServer Pages).
Apache Tomcat 10.1.
Maven.
MySQL.
JDBC.
HTML y CSS.

------- Funcionalidades
Registrar recursos educativos.
Consultar el listado de recursos.
Visualizar los detalles de cada recurso.
Editar y actualizar información.
Eliminar recursos registrados.
